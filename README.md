# PlayWin 已更名为游岚 · YolanLive

正式项目、源码、提交历史、历史发布及最新下载均位于：

**[ShenShenSshen/YolanLive](https://github.com/ShenShenSshen/YolanLive)**

本仓库只保留旧 PlayWin 客户端的升级入口，不维护另一份源码。

## 旧版本升级

在旧版软件中检测更新，可下载 v1.0.8 安装器，直接覆盖安装即可。安装器将程序改为“游岚 / YolanLive”，保留原安装位置、登录、关注、历史及设置，替换旧快捷方式。请不要先卸载旧版，卸载会清空应用数据。

兼容安装包名称为 `PlayWin-1.0.8-x64-Setup.exe`，内容与正式 `YolanLive-1.0.8-x64-Setup.exe` 完全相同。保留旧文件名和仓库路径，是因为已发布的旧客户端会严格校验下载地址。

升级后，软件自动改用 YolanLive 仓库检测后续更新。新用户请从 [YolanLive 发布页](https://github.com/ShenShenSshen/YolanLive/releases/latest) 下载。

为兼容旧资料，数据目录仍为 `%LOCALAPPDATA%\PlayWin`；应用与安装器仍未签名。问题反馈请到正式项目。
